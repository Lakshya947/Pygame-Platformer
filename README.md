A 2D platformer developed in Python using Pygame. The game follows a ninja frog navigating different environments, overcoming enemies and obstacles, and progressing through increasingly challenging levels.
Features
Multiple levels: Five levels featuring different environments and challenges.
Player movement: Running, jumping and gravity-based movement.
Combat system: Fireballs that consume energy and have a cooldown.
Enemy AI: Different enemy types with their own movement and attack behaviours.
Health and energy: Player health and energy systems with visual indicators.
Collectables: Health and mana potions.
Checkpoints: Save progress within levels.
Environmental hazards: Spikes and other obstacles.
Level progression: Different environments, including forests, deserts, hills and caves.

Technologies Used
Python – Main programming language.
Pygame – Game development and rendering.
Object-Oriented Programming – Organising game entities and behaviours.
File Handling – Loading level data from external text files.
